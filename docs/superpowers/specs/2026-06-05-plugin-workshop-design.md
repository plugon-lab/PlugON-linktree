# 플러그인 실습 설계 — 2-3 세션

**날짜:** 2026-06-05
**대상:** Claude Code 기초 사용자 (플러그인 첫 경험)
**시간:** 30분
**방식:** Before/After 비교 — 수강생이 2-2에서 직접 만든 링크트리를 Before로 활용

---

## 배경 및 목표

Part 2 커리큘럼 흐름:
- 2-1: Claude Code 확장 활용 기본 설정
- 2-2: 나만의 링크트리 만들기 (플러그인 없음 → Before 결과물 생성)
- 2-3: 플러그인 설치 + 실습 (After 경험)

목표: 플러그인이 "있고 없음"의 차이를 수강생 본인의 결과물로 체감시키기

---

## 실습 구조 (30분)

### 도입 (3분)
3개 플러그인 설치 확인 후 역할 한 줄 소개

| 플러그인 | 한 줄 역할 |
|---|---|
| frontend-design | Claude의 디자인 감각을 높여준다 |
| playwright | Claude에게 눈을 달아준다 |
| context7 | Claude에게 최신 공식 문서를 검색하게 한다 |

---

### Exercise 1 — frontend-design (10분)

**사전 준비:** 2-2에서 만든 링크트리 브라우저에 띄워두기

**수강생 프롬프트:**
```
2-2에서 만든 링크트리 디자인을 처음부터 다시 만들어줘
```

**수강생이 관찰할 것:**
- 색상 시스템이 생겼는가
- 애니메이션/효과가 추가됐는가
- 폰트 선택이 달라졌는가
- 전반적인 완성도 차이

**강사 포인트:**
> "프롬프트는 완전히 같습니다. 플러그인 하나가 결과를 바꿨어요."

---

### Exercise 2 — playwright (8분)

**수강생 프롬프트:**
```
index.html을 브라우저로 열어서 링크 버튼들이 잘 보이는지 스크린샷으로 확인해줘
```

**Claude가 하는 일:**
1. 브라우저를 실제로 열고
2. 링크트리 페이지 로드
3. 스크린샷 캡처 후 결과 보고

**수강생이 관찰할 것:**
- Claude가 실제로 브라우저를 조작하는 과정
- 스크린샷이 채팅창에 나타나는 순간

**강사 포인트:**
> "Claude에게 눈이 생기는 순간입니다."

---

### Exercise 3 — context7 (7분)

**수강생 프롬프트:**
```
링크트리에 backdrop-filter 효과를 쓰고 싶은데
최신 브라우저 호환성이 어떻게 되는지 공식 문서 기준으로 알려줘
```

**수강생이 관찰할 것:**
- 답변에 출처 URL이 붙는지 여부
- "방금 검색한 정보" vs "Claude의 기억" 차이

**강사 포인트:**
> "출처가 붙으면 방금 검색한 것, 없으면 Claude 학습 데이터에서 나온 것입니다."

## 핵심 설계 원칙

- 프롬프트는 최대한 단순하게 — 차이가 플러그인에서 왔음을 명확히
- 수강생 본인의 결과물(2-2)이 Before → 감정적 몰입도 높음
- 각 플러그인의 역할이 겹치지 않게 분리된 시나리오
- playwright가 가장 극적인 임팩트 → 마지막 전에 배치해 분위기 고조
